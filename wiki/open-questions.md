# 悬而未决（Open Questions）

> 记录**我查了但没查到答案**的问题：上游文档没写、源码看不出、需要实测或需要问上游。
>
> 与错误本互补：`errors.md` 记"答错的"，本文件记"没答上的"。作用是**知道自己不知道什么**，并防止同一个死胡同被反复走进去。
>
> `/dsh-sync` 时会对标记 `retry_on_sync: true` 的条目重新查证（新版本可能已解答）。

## 条目格式

```
### Q<编号> — <问题>
- **已排除的可能**：<查过哪些地方、排除了什么>
- **下一步怎么查**：<具体动作：读哪个文件 / 跑什么实测 / 问上游哪里>
- **阻塞了什么**：<不知道这个会导致哪类问题答不了>
- **retry_on_sync**：true | false
- **发现于**：YYYY-MM-DD · 上游 <短SHA>
```
